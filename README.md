# MovieApp
# 🎬 Movie App (Python + SQLite)

A simple command-line application built using Python and SQLite.  
This app allows users to:
- Add movies with ratings
- View all movies stored in the database
- Get recommended movies with rating ≥ 8

## 🚀 How to Run
1. Install Python 3.x from [python.org](https://www.python.org/downloads).
2. Clone this repository:
   git clone https://github.com/AmanKumar518/MovieApp.git


4. Navigate to the project folder:
5. Run the app:
   python movie_app.py


## 🛠 Tech Stack
- Python
- SQLite
- DBeaver (for database practice)
